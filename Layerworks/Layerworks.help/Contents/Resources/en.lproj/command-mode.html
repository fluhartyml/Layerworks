Command mode

Scripts and bots can run Layerworks without a window:

Layerworks.app/Contents/MacOS/Layerworks --command job.json
Layerworks.app/Contents/MacOS/Layerworks --help

Every file a job reads or writes is a plain name inside the job folder. Choose that folder in Layerworks ▸ Settings…. Until you choose one, jobs use the app's own Command folder (~/Library/Containers/com.nightgard.Layerworks/Data/Documents/Command).

A job file

{ "name": "Two cats", "width": 1024, "height": 1024,
  "steps": [ { "do": "addImage", "file": "cat.png" },
             { "do": "removeBackground" },
             { "do": "exportPNG", "file": "out.png" },
             { "do": "saveProject", "file": "out.layerworks" } ] }

Steps: open, addImage, removeBackground, magicErase (color, tolerance 0–100), merge, resize (width or height; keeps the shape), crop, extend, scaleToFit, exportPNG, saveProject and imagePlayground. Each step works on the top visible picture layer. A job's picture is Untitled in memory; only exportPNG and saveProject write files.

Image Playground needs a person to press Done, so the imagePlayground step saves the project and stops. Open the project and finish it in the window.

Layerworks prints one ok or FAIL line for each step and writes name.status.json. It exits with 0 when every step worked, 1 when a step failed (files from earlier steps are kept) and 2 for a usage error.
