Export, share and print

Choose File ▸ Export… (⌘E), pick a format, then choose where to save it. Formats: PNG, JPEG, TIFF, HEIC, GIF, BMP, PDF, a PDF with one page per layer, an animated GIF of the Camera frames, a print PDF with bleed and marks, a web folder of PNGs, every app-icon size, an Icon Set with light and dark versions (Mac), and a video from the Storyboard.

If the picture has a mask, only what's inside the mask is exported.

The Share button on the toolbar sends a PNG through Messages, Mail, AirDrop and the rest of the share sheet, including Save to Photos.

File ▸ Print… (⌘P) prints the picture. For a printer's file, choose the print PDF in Export and set bleed, safe margin, crop marks, registration marks and RGB or CMYK there.
