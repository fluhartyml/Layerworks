Make, open and save a picture

Choose File ▸ New (⌘N) for a new 1024 × 1024 picture. It's named Untitled (then Untitled 2, and so on) and lives only in memory: nothing is written to disk until you save it the first time.

Choose File ▸ Save (⌘S) to name it and pick where it goes. After that first save, your Mac saves your changes as you work, and File ▸ Revert To ▸ Browse All Versions… shows earlier versions.

File ▸ New from Import… (⇧⌘N) starts a picture from an image file, at that picture's size. The original file is never changed.

Image Producer files

Layerworks opens Image Producer projects (.imgprd, .picprod and .iconproj) as imports. Saving writes a new .layerworks file; the old file is left as it was.

Canvas size

Pick the Canvas Tool (C) to set the width, height and print resolution, or choose a preset. Keep proportions keeps the shape; the swap button turns portrait into landscape.
